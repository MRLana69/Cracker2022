Projeto experimental Subway Crackers preparado para Unity 2022.3.0f1.

Esta cópia combina a exportação do AssetRipper com 1.305 scripts C# aproximados reconstruídos por Cpp2IL/ILSpy. Os arquivos .meta dos stubs substituídos foram preservados para manter os GUIDs de cenas e prefabs.

Limitações:
- Os fontes reconstruídos não são o código-fonte original e ainda não foram validados no Unity Editor.
- A compilação externa dos fontes encontrou erros significativos; o Build Automation pode falhar até que os scripts sejam corrigidos.
- O Unity Editor não estava instalado no ambiente que preparou esta cópia, portanto a abertura, reimportação, compilação e execução não foram testadas.
- Esta publicação contém apenas Assets, Packages e ProjectSettings do projeto; os artefatos de recuperação e backups não estão incluídos.
