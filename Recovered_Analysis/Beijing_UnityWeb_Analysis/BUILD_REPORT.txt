LIMITAÇÕES IMPORTANTES
Isto é uma tentativa abrangente de análise e reconstrução, não uma descompilação perfeita nem restauração do projeto-fonte original. O IL2CPP converteu o código C# em código nativo/WebAssembly; nomes, tipos, estrutura de alto nível e informação de editor podem ter sido perdidos na compilação. As ferramentas podem reconstruir metadados, assinaturas, instruções aproximadas e trechos de lógica, mas não recuperar informação eliminada.

O Cpp2IL registrou 14.475 ocorrências de métodos sem corpo lido e, nas saídas adicionais, avisos sobre assinaturas WASM não associadas e métodos grandes ignorados. O pseudocódigo WASM não é C# equivalente ou fonte original. Os DummyDlls do Il2CppDumper preservam assinaturas/metadados e não contêm a lógica original completa. Os formatos adicionais não eliminam essas lacunas nem permitem garantir “sem erros e nada faltando”.

A build e o projeto exportado não foram abertos, recompilados ou validados no Unity Editor. A exportação do AssetRipper não é um projeto Unity integral reconstituído; o log indica backend de scripts “Unknown” e contém avisos de conversão de áudio. Os scripts auxiliares exportados não recuperam a lógica completa.

Os dados foram mantidos localmente neste pacote. Nada foi publicado no GitHub e o projeto atual não foi alterado.
